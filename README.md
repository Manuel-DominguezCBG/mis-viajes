# Mis viajes

Mapa interactivo de rutas y sitios, reconstruido a partir de la Cronología de Google,
fotos con GPS, mapas de pared dibujados a mano, el calendario y el archivo de correo.

Se ve en la página del repositorio. Filtra por medio de transporte y por mes; el botón
de reproducir lo recorre mes a mes.

Es una versión pública y depurada: no incluye el rastro diario ni los alrededores del
domicilio y el trabajo.
